# Self-review

## Score: 26 / 30

### Direction fidelity: 9 / 10

The rail is Linear (36px, inset accent, grouped labels, workspace mark). Home is a Settings index plus Today feed. Schedule is a week canvas with paste in the inspector. Semester is a Notion page. Forum is an issue list. That is a different product from Round 1, not a theme swap.

Deduction: the site header is still a club publication bar (wordmark, About, Events, Sign up). Linear products usually eat the top of the window. The assignment requires the club header and Account there, so the split is correct and slightly less "Linear app" than a standalone shell.

### Information design: 8 / 10

Nine surfaces, grouped rail, picker, hash routing, sample labels. Schedule shows overlap as two blocks plus the word Overlap, not color alone. Free time reuses week geometry as gaps. Catalog term filter is on-page only. Books say reference only. Forum composer is a bottom bar, not the page.

Missing in this static cut: loading skeletons, empty search, signed-out composer gate, locked thread, three-way collision, and a list view of Schedule (the Week/List segment is visual only). Invented club names besides Programming Club are preview sample.

### Visual craft: 9 / 10

Cool paper/ink, 13px UI, 4–6px radius, hairline rules, tabular times, focus rings, reduced motion, mobile drawer. Week grid uses a time rail and positioned blocks. Type is Inter / Inter Tight only.

Deduction: tablet widths still scroll the week sideways under 52rem without a "days continue" cue. A few peek panels use one inline style for margin. The mobile drawer is a class toggle, not focus-trapped Popover.

## Thumbnail test

Schedule is a registrar week with a mist rail. Forum is an ID-prefixed issue index with a 40px toolbar. Neither can be mistaken for heading + lead + form.
