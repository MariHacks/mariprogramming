What should I review before the first Data Structures lab?

Started by Maya L. on September 15

MLMaya L.Original poster

I took the introductory programming course last term, but I have not used linked lists yet. The outline mentions them in the first lab.

Should I review pointers first, or is the lab meant to introduce both ideas together? I am mainly trying to avoid getting stuck on setup.

Yesterday at 19:42
JRJon R.420-202 student

Review arrays and object references first. We did not need manual pointers. The starter exercise explains the node structure before the graded part.

The setup check took about ten minutes once Java was on the right version.
Yesterday at 20:10
NKNora K.Course mentor
Helpful answer

The most useful review is tracing an array operation by hand, then doing the same with two objects that refer to each other. The lab instructions introduce the linked-list vocabulary.

Also confirm that the course repository builds before the lab. If that step fails, post the error text without your student number.
